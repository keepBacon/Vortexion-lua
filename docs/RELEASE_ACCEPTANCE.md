## 本轮补修

共享 UI 消除原生拒收导致的滑块状态分裂，释放事件合并为一次延迟提交，锁定与卸载不残留重试；配置子项失败隔离；初始化中断回收本次拥有的资源；构造暂停期间卸载后，晚到窗口不进入设置/监听安装，直接回收自身资源，原始异常保留且既存外部资源不受影响。窗口返回后仍按初始化阶段复查存活；晚到切服句柄停止一次，配置枚举恢复时中止后续控件与监听注册，避免再次销毁已取得并清理的窗口。布局/摄像机观察器、下拉去重与手机默认设置均保留。AOTR 新增触点稳定队列、右侧默认区域、失焦释放及角色属性快照恢复，未增加远程名称或协议参数。

配置操作新增单飞门禁，并在正常完成与错误后释放；候选配置完整注册与选定后才更新桥层缓存，卸载清空公开桥层配置句柄。发行库内部会提前设置 `native.CurrentConfig` 和管理器缓存，夹具已模拟该副作用，桥层延迟公开不等于原生管理器事务。每个外部调用恢复后复查存活；已进入的外部文件调用可能完成，不宣称撤回磁盘副作用。手动加载直接调用原生加载器，旧自动加载入口始终关闭。新增暂停配置健康保存/加载对照、准备/注册/选定失败重试、改名失败保留旧桥层句柄、逐 ID 注册校验，以及保存/加载/删除/列表异常后的门禁释放。保存/加载/删除返回 false 不再报告成功且可重试；晚到候选的旧加载入口被封闭，卸载后的加载失败不改写旧错误状态。新增 26 项，原 26 项保持通过。

回调生命周期新增 20 项契约，原 52 项保持通过：主回调/首个监听卸载及协程恢复后中止分发，清理协程暂停时也不接纳旧活动事件；事件代际识别值先变更再回到原值的重入，200 轮突发不重播旧事件。同值幂等设置仍交付一次正常事件；分发期间添加的监听只立即初始化一次，不重复进入本轮。卸载释放监听闭包与待提交值，晚到注册不留存；旧回调/通知失败不改写已关闭错误状态，原生设置恢复后不读取销毁对象。健康暂停回调、活动错误提示、清理业务重置与清理错误诊断对照均保留。设置器与通知暂停使用局部仪器化接口；不宣称中断已经进入的原生调用或测得实机内存/FPS 改善。

移动布局新增 20 项契约，原 72 项保持通过：缩放监听/暂停恢复后的卸载、关闭自动适配与全屏状态中止后续居中；布局代际防止重入后重复居中。相机、视口、窗口尺寸变化合并排队一次新布局；先判断相机身份，再读取视口，避免访问替换前对象。仅当居中正常返回且布局仍最新时提交缓存，失败可重试，旧暂停居中不覆盖较新布局缓存，居中暂停后卸载不再读取失效尺寸。新增布局夹具逐例核对没有异步任务错误。健康缩放/居中暂停对照通过；100 轮视口重入每轮只完成一次最新布局居中调用。原生方法返回不等于 Tween 动画结束。已进入的原生缩放/居中调用仍可能完成，不宣称撤回；暂停、失效旧相机及原生错误为局部仪器化，旋转次数与调用计数不等于实机 FPS。

下拉列表新增 20 项契约，原 92 项保持通过。桥层列表仅在原生 Refresh 正常返回且仍存活时提交；失败保留已提交列表、标记原生状态可能不完整，同一请求或旧列表都可显式重建恢复。SetValues 列表请求串行化，暂停/重入期间只保留最新快照，每批最多同步重建 8 次，剩余由一次延迟任务继续；500 次嵌套请求只做初始和最终两次重建。卸载清空待刷新列表，晚到返回不发布桥层缓存；失败终止当前批次并清空待办，延迟任务失败仍显示诊断，之后可显式重试。覆盖空列表、输入类型、深拷贝与原生 Select 的正常选择事件。执行真实发行库 Callback、Refresh 提交尾段和 Select，菜单项/图标构建与调度为局部夹具；不保证撤回已进入原生调用，不宣称串行化并发 Select 与 SetValues 的完整菜单构建，也没有实机帧率结论。

AOTR 渲染复用既有标签，100 次稳定刷新无新增实例；缓存 30 轮文件夹替换后只保留当前两条监听，不在应用回收表堆积失效句柄。名称、生命、距离独立显示；动态高亮及显示距离即时同步。卸载后延迟更新不复活，死亡/部件移出/场景消失使已持有条目引用失效。保持原公共 API 与选择逻辑。发布验证器新增 10 套件、归档器新增 7 个隔离测试，验证快照变更、失败阶段、同名输出保留和读取竞态均有回归。
