# R2.18 — Forsaken 新版发电机适配（来自 2026-10-17 实机资料）

## 一、依据与实现边界

**用户提供** `数据.zip`，其中 `一些数据.txt` 以及 4 段安卓录屏，均已离线分析。录屏内容显示：

- 7×7 网格连线：49 个 `Grid/<index>` 按钮，`Circle/Number.Text` 和颜色用于两端配对。文字数据包含 8、11、12 对端点的实例与有效的非交叉解路径；解路算法用三组独立棋盘重新计算，通过路径不跨格、不交叉、不越界校验。
- 12 个外围节点：`Grid/Blobs/1..12`，UI 有 `Lines/Line`，视频显示不同颜色的两点通过直线连接。R2.18 新增按**节点 Frame 实际颜色**配对，若实际背景色不能代表端点色则返回 `incomplete`，不会猜配对。
- 圆锁／开锁：录屏显示白色目标弧、移动的红色指针及剩余数量，但没有可读的 `Rotation` 实时属性或“何时按键”的回调接口。该题型目前不自动操作。
- 齿轮题：`123.txt` 和 `数据.zip` 提供 `Inventory/GearElement/CenterGear/CenterLeft/CenterRight` 静态节点，无齿轮类型与对应插槽、拖动后状态、输入事件和操作录像。目前识别为 `gear`，不自动乱点。

**外部社区资料**：2026-10-16 的新版目标玩法公开视频展示了 Wire、Gear、Graffiti、Feed the orange、Pop the lock 等多种小游戏。这些不应一概视为四种固定发电机题型；以用户真实 `PuzzleUI` 为准。

## 二、已实现的真实代码

新增 `src/ForsakenPuzzleAuto.luau`，并由 `ForsakenCore.luau` 向 `ForsakenEnhancements.luau` 注入。

1. 自动开启：当 `自动修发电机` 启用且有可见 `PlayerGui.PuzzleUI.Container` 时，优先处理正在显示的谜题；不再因为发电机距离检查而忽略已打开的界面。
2. 网格：从真实 GUI 提取 7×7 端点，用 `ForsakenPuzzlePlanner.Solve` 求解不交叉路径，逐格投递按下、移动、抬起事件。
3. 外围连线：根据同色节点配对，尝试点对点拖动；无配对、配对歧义或观察不到连线时不继续。
4. 输入后端：安卓触屏优先尝试受限的 `VirtualInputManager.SendTouchEvent`；否则尝试执行器的鼠标函数或虚拟鼠标接口。常规 Roblox 客户端脚本不能直接使用 `VirtualInputManager`；依赖执行器能力。
5. 安全：每路径结束后检查可见 Line 数是否增加或题目切换；未得到证据即停止，同一未确认盘面不重复发送触控。关闭功能、卸载、谜题隐藏或系统菜单打开时终止并释放按键。
6. 新增两次间隔 0.22 秒的动态属性采集按钮，用于采集圆锁、齿轮的 `Rotation`、位置、颜色、图片 ID、文字和少量属性，最多 260 个 GUI 对象。
7. 诊断区会显示执行器能力、路径次数、失败次数、最近错误。对 `FireServer()` 仍不将返回正常算作进度完成。

## 三、未实现 / 需要提供的事实

**暂时不能宣称四种新版发电机全自动可用。**

- 虚拟输入是否被 Android 执行器允许、是否被 Roblox 的 PuzzleUI 接收，当前缺实机反馈。
- 线条新增是否直接体现在 GUI 节点：R2.18 通过新增 `*Line*` GUI 及界面替换判定；如果游戏复用已有 Line 并仅改变属性，可能出现保守的“未确认”并暂停。
- 12 节点外围题需要确认 `Blobs/<n>.BackgroundColor3` 与实际图案颜色相同；否则必须改用真实 `ImageColor3` 等字段。
- 圆锁：需要打开圆锁时使用「复制齿轮／开锁动态结构（两次采样）」按钮，提供红色指针和白弧节点的真实属性变化，再录一段成功/失败按键动作。
- 齿轮：需要实际齿轮题打开时采集两次动态结构，以及演示哪个齿轮如何拖到哪个槽的录像。
- 服务端完成：需要实机证实每层成功后 `Progress.Value` 或游戏目标计数确实增加。

## 四、实机验收顺序

1. 加载 R2.18 并靠近未完成发电机。手动开启谜题，打开 Vortexion 的「自动修发电机」，随后**收起脚本窗口**，避免 UI 遮挡游戏原本的 PuzzleUI。
2. 7×7 题出现时等待 5 秒，观察脚本是否自主绘制第一条线；不要同时手动拖动。
3. 检查「查看修理与防御诊断」的 `路径执行`：`input-unavailable`（执行器没有权限）、`incomplete`（没有可靠配对）、`unconfirmed`（虚拟触控没有被游戏接受）、`await-next-board`（已试图完成，等待服务器或 UI 转场）。
4. 如发生输入问题，立即关闭自动修理或卸载功能，确保已释放输入状态；保留本轮诊断，不连续重试。
5. 处理锁与齿轮时，采集动态 GUI 属性数据并提供一个完整手动通过的视频。它们暂未启用自动操作。
