# Forsaken R2.8 — 七项功能与运行限制

## 功能

| 功能 | 开关与范围 | 真实实现 | 注意 |
|---|---|---|---|
| 无限体力 | 角色→开关 | 安全 require 游戏 Sprinting 模块，维护 `StaminaLossDisabled`、`StaminaLoss`、`StaminaGain` 与当前体力；关闭时恢复配置 | 客户端修改是否被服务器接受需真机确认；不更改上限 |
| 反减速 | 角色→开关 | 仅维护角色 `SpeedMultipliers.SlowedStatus` 与 `FOVMultipliers.SlowedStatus`，关闭时恢复原值 | 只针对已知本地乘数，不覆盖服务器状态 |
| 反塔夫亚空间炸弹 | 防御→开关 | 隐藏本地 `Subspaced`、`SubspaceEffect`、`SubspaceOverlay` GUI 或 Lighting 后处理效果，关闭时恢复 | **不是**真正的无敌/免控；服务端 `Helpless` 仍可能生效 |
| 自动关闭 1x1x1x1 弹窗 | 防御→开关 | `TemporaryUI/1x1x1x1Popup` 事件触发，尝试 VirtualInputManager 点击（若可用），本地隐藏兜底 | 隐藏界面不代表服务端状态解除；Android 执行器可能不提供 VIM |
| 移动倍率 1.0–2.0 | 角色→滑块 | 按 Humanoid WalkSpeed 的基准值乘倍率，非连续叠加；关闭还原 | 游戏的服务器或动画可能继续覆盖速度 |
| 自动修发电机 | 发电机→开关 | 只处理游戏地图内未完成的 `Generator`，优先近距离，使用已知 `Remotes.RE`，检查 `Progress` 是否变化，连续失败暂停 | 不臆造成功；远程协议/范围随游戏更新可能失效。可选自动前往默认为关 |
| 修发电机延迟 | 发电机→2.5–10 秒滑块 | 限定每次修理请求之间的最小间隔 | 设置延迟不是修复时间承诺 |

## 架构与保护

- 新增独立工厂 `src/ForsakenEnhancements.luau`，不复制旧的上千行脚本，不增加外部 `loadstring` 依赖。
- 一个 4Hz `Heartbeat` 调度器仅在至少一项功能启用时运行；弹窗与 UI 效果使用 `DescendantAdded` 订阅，不在每帧遍历 Workspace。
- 玩家重生会重置速度/减速对象引用、发电机追踪目标，重新获取 Sprinting 模块。
- 用户取消、UI 关闭或二次加载会释放调度器、事件连接、游戏临时值（能安全恢复者）、视觉隐藏效果、自动前往位置。
- 发电机自动前往使用本地 CFrame 写入，不表示服务端允许传送；请勿把客户端表现当作服务端进度。
- 发电机远程使用现有参考代码的 `Generator.Remotes.RE:FireServer()` 作为版本假设，不自动高频重复或暴力遍历全图。修理是否有效应观察 Progress 的真实变化。

## 验证范围

- 6 个 Lua 5.4 模拟测试（功能切换、恢复原值、事件清理、移动倍率、修理间隔及远程调用、构建产物一致性）。
- 旧版与共享模块的 77 项相关回归；共 83 项维护中的单元/静态检查通过。
- 六个模块化 + 六个独立产物在本地重新构建，并校验 SHA-256。
- **没有 Roblox 安卓真机测试，也未连接实际服务器验证 7 项 gameplay 效果**。

## 测试顺序

1. 执行 `loader.lua` 并进入 Forsaken；确认“角色 / 防御 / 发电机”分页存在。
2. 先单独启用无限体力、反减速、移动倍率，检查 UI 事件与重生后恢复。
3. 进入有 Taph 与 1x1x1x1 的场景，验证本地视觉及弹窗处理是否有效。
4. 靠近未完成发电机，启用自动修理，观察真实 Progress 值；若位置较远，可手动打开“自动前往”，谨慎测试。
5. 使用“查看修理与防御诊断”查看请求计数、进度变化和异常。如果没有进度增长，不能把远程请求当作成功。
